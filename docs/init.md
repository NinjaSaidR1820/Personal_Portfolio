# Inicialización del Proyecto: Portafolio Denis Said Rivas Sánchez

## Visión General
Este proyecto es un portafolio profesional de alto impacto diseñado para **Denis Said Rivas Sánchez**, Ingeniero de Sistemas, Desarrollador y Analista de Soporte IT. El objetivo principal es convertir visitas en oportunidades laborales mediante una narrativa centrada en resultados y una estética "Matte Dark" moderna.

## Stack Tecnológico
- **Framework**: Next.js 15 (App Router)
- **Lenguaje**: TypeScript
- **Estilo**: Tailwind CSS + ShadCN UI
- **IA**: Genkit (para el explicador de habilidades)
- **Iconografía**: Lucide React
- **Fuentes**: Inter (Cuerpo y Títulos)

## Configuración de Marca
- **Nombre**: Denis Said Rivas Sánchez
- **Estética**: Matte Dark (Carbono, Rojo Mate, Acentos Azul/Naranja)
- **Tipografía**: Jerarquía clara con énfasis en negritas para nombres y cargos.
- **Navegación**: Híbrida (Superior en Desktop / Inferior en Mobile) para UX optimizada.

## Estructura de Páginas
1. `/` (Home): Hero, Proyectos Estrella, Servicios Principales y Experiencia Laboral.
2. `/works` (Proyectos): Galería de trabajos detallados con enlaces a GitHub.
3. `/skills` (Habilidades): Ecosistema tecnológico, Educación y Certificaciones.
4. `/hobbies` (Pasiones): Logros personales y galería visual de intereses.
5. `/contact` (Contacto): Formulario de conversión y enlaces directos.
